# zShield-utils

Various utilities to use with zShield Pro and Enterprise. The utilities are hosted in the corresponding folders. This file provides an overview of the available utilites, while detailed instructions are available in dedicated readme files.

For more information on zShield Pro, consult the official documentation (available in the console to current customers or prospects) or [Zimperium Website](https://zimperium.com/maps/zshield).

## zShield Pro

zShield Pro utilities currently include:

- **zShieldPro Protect** - Bash and PowerShell scripts used to upload binaries to Zimperium, wait for protection to complete, and download protected binaries as artifacts.
